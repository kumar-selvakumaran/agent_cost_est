## Row-per-trial vs row-per-episode (§4.2)

Trials (terminus-2 main rows with trial_name): 1,198,471; trials with >1 row: 193,548 (16.1%), holding 508,912 rows. Task-id agreement: `task` == `trial_name` prefix in 95.5% of rows with both (the difference is entirely the `_copyN` suffix convention); name-based task id (with `_copyN` stripped) vs hash of the task statement: 95.2% of runs carry the modal statement of their task name; 14.4% of distinct statements appear under more than one task name. Task names are therefore not reliable identifiers (names such as `swesmith-00088` or `acl-permissions-inheritance` are reused across source repos for different statements). **Resolution (conservative): task_id = hash of the exact task statement** (cell = statement × model); CV groups = connected components linking task names and statements, so neither a shared name nor a shared statement can straddle train and test.
